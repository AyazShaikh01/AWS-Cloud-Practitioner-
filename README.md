# ☁️ AWS Cloud Practitioner – Study Notes

A structured collection of notes to understand **Amazon Web Services (AWS)** and prepare for the **AWS Certified Cloud Practitioner (CLF-C02)** certification.

This repository organizes important AWS services, concepts, use cases, pricing models, and exam-focused comparisons into easy-to-follow Markdown notes.

Whether you're starting your cloud journey or revising before the certification exam, use this repository as your learning and quick-reference guide.

## 🎯 How to Use These Notes

1. **Start with a topic:** Choose one of the seven sections.
2. **Understand the services:** Focus on what each AWS service does and why it exists.
3. **Compare similar services:** Pay attention to differences between services that perform similar functions.
4. **Remember the use cases:** Understand which service fits a particular real-world scenario.
5. **Revise regularly:** Revisit the notes to strengthen your understanding.
6. **Practice exam questions:** Apply what you've learned to CLF-C02-style scenarios.

## 🧠 Key Areas to Focus On

For the AWS Cloud Practitioner certification, make sure you understand:

- AWS Global Infrastructure (Regions, Availability Zones, Edge Locations).
- AWS Shared Responsibility Model.
- Identity and Access Management (IAM).
- Compute services (EC2, Lambda, ECS, EKS).
- Storage services (S3, EBS, EFS).
- Database services (RDS, DynamoDB).
- Networking services (VPC, Route 53, CloudFront).
- Monitoring and governance (CloudWatch, CloudTrail, AWS Config).
- AWS pricing models and billing tools.
- Migration and cloud adoption concepts.
